This release adds an explicit Move mode for Quick Translate and fixes two Chinese-text display issues.

## Which file to download

| System | Package |
| --- | --- |
| Ubuntu 22.04, 24.04+, or Debian 12+ | `LightTranslator-1.6.3-amd64-ubuntu22.04-or-newer.deb` |
| Ubuntu 18.04–20.04 | `LightTranslator-1.6.3-amd64-ubuntu20.04-or-older.deb` |

Install with `sudo apt install ./<package-name>.deb` so dependencies are resolved automatically. The two builds conflict and cannot be installed together.

## Quick Translate

- Click Move, then drag the blank header area. The popup keeps its rounded, translucent appearance and stays open when focus changes or you click elsewhere.
- Turn Move off to restore dismissal on the next focus loss. Close, Escape while focused, and Open in main window still close it. Each new shortcut invocation resets Move and places the popup near the pointer; movement is never saved.
- Short translations now show the complete final line above the footer. Size measurements include the browser's scrollbar space, preventing a scrollbar from adding an unmeasured wrapped line. Long results still scroll after reaching the 500px height limit.
- The bundled GNOME placement helper clamps resizing to the popup's current monitor after movement. A new login may be needed to load the updated helper.

## Source-text typography

The original-text column now follows the selected source language. Auto Detect derives a local rendering hint from Japanese kana, Korean Hangul or Han characters. Han text without kana or Hangul uses Simplified Chinese typography, including bottom-positioned periods. This hint changes display only; it does not change input, translation languages or provider requests.

## Validation and known limits

TypeScript checks, production build and Node tests pass. The shared source passed 67 sizing and Move checks in each of WebKitGTK and Chromium, plus native Wayland dev-app acceptance. Native Electron non-resizable popup sizing and physical multi-monitor/helper acceptance remain separate follow-ups; Chromium geometry checks use a resizable fixture.

The Ubuntu 22.04+ package was built in a jammy container and has a GLIBC 2.34 floor. Both Debian archives contain version 1.6.3, desktop files, icons and GNOME helper version 2. The Electron archive includes the matching production frontend and native Move implementation.
